01

팀 소개

문제를 풀고, 원리를 파고듭니다.

활빈당은 국제 CTF 대회에 참가하고 보안 취약점을 연구하는 해킹팀입니다. 함께 문제를 분석하고 풀이를 나누며, 버그 바운티 프로그램의 허용 범위 안에서 발견한 취약점을 제보합니다.

02

연구 분야

보안 문제를 이해하는 네 가지 관점.

Web Security

서비스의 동작부터 취약점까지.

HTTP 통신, 인증과 권한, 브라우저와 서버의 동작을 분석하는 분야입니다. 서비스가 입력을 처리하고 데이터를 주고받는 과정에서 생기는 취약점을 다룹니다.

  • HTTP
  • Authentication
  • Browser

System Security

메모리와 실행 흐름을 따라.

메모리 구조와 운영체제, 프로그램의 실행 흐름을 분석하는 분야입니다. 메모리 취약점이 발생하는 원인과 이를 막는 보호 기법을 다룹니다.

  • Memory
  • Linux
  • Mitigation

Reverse Engineering

바이너리에서 동작을 읽어냅니다.

컴파일된 프로그램을 분석해 내부 로직과 데이터 흐름을 파악하는 분야입니다. 어셈블리와 디버깅을 통해 소스 코드 없이 프로그램의 동작을 이해합니다.

  • Assembly
  • Binary Analysis
  • Debugging

Cryptography

암호의 원리와 구현을 살핍니다.

암호 알고리즘과 프로토콜의 수학적 구조를 분석하는 분야입니다. 설계상의 가정과 구현의 차이에서 생기는 취약점을 다룹니다.

  • Mathematics
  • Protocols
  • Encryption

자주 묻는 질문

팀과 활동에 대한 안내.

활빈당은 어떤 팀인가요?

국제 CTF 대회에 참가하고, 보안 취약점 연구와 버그 바운티 활동을 하는 해킹팀입니다.

어떤 분야를 다루나요?

웹 보안, 시스템 보안, 리버스 엔지니어링, 암호학을 소개합니다. 연구 분야 탭에서 각 주제의 설명을 확인할 수 있습니다.
