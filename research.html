02

네 가지 시선

보안 문제를 이해하는 네 가지 관점.

Web Security

서비스의 동작부터 취약점까지.

HTTP 통신, 인증과 권한, 브라우저와 서버의 동작을 분석하는 분야입니다. 서비스가 입력을 처리하고 데이터를 주고받는 과정에서 생기는 취약점을 다룹니다.

  • HTTP
  • Authentication
  • Browser

System Security

메모리와 실행 흐름을 따라.

메모리 구조와 운영체제, 프로그램의 실행 흐름을 분석하는 분야입니다. 메모리 취약점이 발생하는 원인과 이를 막는 보호 기법을 다룹니다.

  • Memory
  • Linux
  • Mitigation

Reverse Engineering

바이너리에서 동작을 읽어냅니다.

컴파일된 프로그램을 분석해 내부 로직과 데이터 흐름을 파악하는 분야입니다. 어셈블리와 디버깅을 통해 소스 코드 없이 프로그램의 동작을 이해합니다.

  • Assembly
  • Binary Analysis
  • Debugging

Cryptography

암호의 원리와 구현을 살핍니다.

암호 알고리즘과 프로토콜의 수학적 구조를 분석하는 분야입니다. 설계상의 가정과 구현의 차이에서 생기는 취약점을 다룹니다.

  • Mathematics
  • Protocols
  • Encryption
