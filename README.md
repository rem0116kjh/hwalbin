# 활빈당 · Hwalbin

국제 CTF에 참가하고 보안 취약점을 연구하는 해킹팀 활빈당의 홈페이지입니다. 한국어 본문과 페이지 구조는 `index.html`, `about.html`, `research.html`, `activity.html`, `faq.html`에 있고, 스타일은 `assets/style.css`, 동작과 영어 번역은 `src/main.ts`에 있습니다.

## 실행과 빌드

```sh
npm ci
npm run check
npm run build
python3 -m http.server 8000 --bind 127.0.0.1
```

브라우저에서 http://127.0.0.1:8000/ 을 엽니다. `src/main.ts`가 원본이며, 컴파일 결과 `assets/main.js`도 저장소에 함께 관리합니다. 정적 호스팅에는 다섯 HTML 파일, `robots.txt`, **`assets` 폴더 전체**가 필요합니다. 별도 서버 API나 프레임워크는 사용하지 않습니다.

## 구성과 디자인

- 홈: 한글 팀명, 성곽 배경, 각 페이지로 가는 카드와 민화풍 풍경 링크
- 팀 소개 페이지: 소개문과 주요 활동·소개 분야·공개 기록
- 연구 분야 페이지: 웹·시스템·리버싱·암호학 탭, 방향키와 Home/End 지원
- 활동 기록 페이지: 대표 대회 결과와 Hack.lu·HITCON·FAUST 순위, 제공된 대회 링크
- FAQ 페이지: 기본 HTML `details`로 제공
- 한국어·영어 전환, 밝은·어두운 테마, 모바일 메뉴, 페이지 간 탐색
- 언어·테마 설정 저장, 키보드 탐색, 모션 감소 설정 지원

먹색·따뜻한 흰색·붉은색을 사용합니다. 첫 화면과 하위 페이지의 머리말은 테마에 따라 어두운 성곽과 밝은 낮 풍경을 표시합니다. 기본 테마는 어두운색입니다. 홈 하단의 민화풍 풍경은 연구 분야 페이지로 연결되며 포인터 이동에 반응합니다. 동작 줄이기 설정에서는 움직이지 않습니다. 홈 팀명과 주요 제목, 탭·FAQ 질문에는 설치된 궁서 계열 글꼴을 우선 쓰고, 없으면 Noto Serif KR 등을 사용합니다. 긴 본문은 Noto Sans KR을 사용합니다.

JavaScript가 꺼져 있어도 한국어 본문과 링크, FAQ는 읽고 이용할 수 있습니다. 언어를 전환해도 선택한 연구 탭과 펼친 FAQ는 유지됩니다.

## 활동 기록 출처

ASIS 결과와 개최일은 2026-10-24에 [Hwalbin CTFtime 팀 프로필](https://ctftime.org/team/304129)과 대회 결과표에서 확인했습니다. 홈페이지의 ASIS 날짜는 **한국시간(KST)** 기준입니다. 나머지 순위는 팀이 제공한 기록입니다.

| 대회 | 홈페이지에 표시한 결과 | 링크·출처 |
| --- | --- | --- |
| ASIS CTF Quals 2026 | 2026.08.29–30, 608개 팀 중 10위, 1,907점 | https://ctftime.org/event/3033 |
| Hack.lu CTF 2026 | 24등 | https://flu.xxx/ · 팀 제공 |
| HITCON CTF 2026 | 15등 | https://ctf2026.hitcon.org/ · 팀 제공 |
| FAUST CTF 2026 | 60등 | 팀 제공 |

기록은 정적으로 표시하므로 새 결과를 추가할 때 원문을 확인하고 한국어와 영어를 함께 수정합니다. 참가 예정 상태를 완료된 실적으로 표시하지 않습니다. 확인되지 않은 연구 글, 팀원 정보, 연락처, 모집 일정은 추가하지 않았습니다. 지원 접수나 메시지 전송 기능은 없습니다.

## 숨은 플래그

기존 이스터에그를 유지합니다. HTML 주석, 콘솔 힌트, `robots.txt`의 가짜 경로, 홈의 상단·하단 로고를 합해 5회 클릭하는 동작으로 탐색할 수 있습니다. 로고 5회 클릭 시 플래그 창이 열리고, 닫기 버튼이나 Escape로 닫습니다. 새로고침하면 클릭 횟수가 초기화됩니다. `/vault/flag.txt`는 힌트용 경로이며 실제 파일이 아닙니다.
